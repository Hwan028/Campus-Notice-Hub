# [프로젝트 기획] 캠퍼스 통합 공지 키워드 구독 및 스마트 알림 서비스

## 1. 기본 정보
* **프로젝트명:** 캠퍼스 알리미 (Campus-Notice Hub)
* **개발 분야:** Backend API Server & Cross-Platform Mobile Client
* **목표 일정:** 이번학기
* **기술 스택:**
  * **Backend:** Java 17, Spring Boot 3.2.x, Spring Data JPA
  * **Database:** MariaDB 10.11 LTS
  * **Web / Crawler:** Spring Web, Jsoup Library 1.17.x
  * **Frontend:** Flutter (Dart), //Riverpod, Dio, Freezed, Hive
  * **API Docs:** Swagger (Springdoc-OpenAPI v2.3.0)

---

## 2. 기획 배경 및 문제 정의

1. **공지사항의 파편화**
   * 대학 포털 내 공지사항이 대학 (학사/행사/장학/채용/일반), 학과 공지, 학과취업공고, 학교취업공고 여러개의 웹페이지로 분산되어 있음.
2. **정보 탐색의 비효율 및 기회비용 발생**
   * 학생들이 게시판을 일일이 찾아보기 어려워 **국가근로/교내장학금, 학과 사물함 신청, 자격증 응시료 지원 ** 등 혜택을 놓치는 경우가 발생.
3. **해결 방안**
   * 분산된 교내 웹 공지사항을 백엔드 스케줄러가 자동으로 통합 수집(Crawling)및 정제하고, 학생의 소속 학과 및 사용자 맞춤 키워드에 맞춰 필터링된 맞춤형 피드 및 푸시알림 제공.

## 3. 핵심 기능 명세

### (1) 온보딩 및 키워드 설정
* **학교 및 소속 학과 설정:**
  * 재학 중인 대학교 및 소속 학과를 선택하여 해당 학과의 공지까지 통합 수집 범위로 지정.
* **원클릭 추천 키워드(프리셋) 제공:**
  * **[학사/수강]** `#수강신청`, `#계절학기`, `#사물함`, `#졸업요건`, `#휴학/복학`
  * **[장학/지원금]** `#국가장학금`, `#교내장학`, `#근로장학생`, `#응시료지원`, `#생활비대출`
  * **[취업/스펙]** `#현장실습`, `#인턴십`, `#자격증`, `#SW사업단`, `#공모전`
  * **[캠퍼스 복지]** `#기숙사/생활관`, `#노트북대여`, `#동아리`, `#축제`
* **사용자 커스텀 키워드 등록:**
  * 프리셋 외에 본인이 원하는 단어 직접 추가/삭제 가능.

### (2) 백엔드 자동 수집 및 처리 파이프라인 (Spring Boot)
* **주기적 공지 크롤링 (`@Scheduled` + `Jsoup`):**
  * 1시간 간격으로 등록된 학교/학과 게시판 HTML 파싱.
* **중복 적재 방지 및 정제:**
  * 게시글 고유 URL/번호를 식별자로 사용하여 신규 글만 MariaDB에 적재.
* **키워드 매칭 및 피드 생성 API:**
  * 유저의 소속 학과 공지 + 유저가 등록한 키워드가 포함된 공지만 선별하여 최신순 정렬 반환.
* **푸시 알림 발송:**
  * 크롤링 시 신규 공지가 등록되면 해당 키워드/학과를 구독 중인 유저에게 알림 발송.

### (3) 프론트엔드 (Flutter Mobile App)
* **홈 맞춤 피드:** 매칭된 키워드 태그가 부착된 공지 카드 렌더링 (Pull-to-Refresh 지원).
* **전체 공지 탐색:** 카테고리별(학사/장학/취업/학과) 전체 공지 조회 및 검색.
* **공지 상세 웹뷰(WebView):** 공지 카드 터치 시 해당 학교 공식 원문 페이지로 매끄럽게 연결.
